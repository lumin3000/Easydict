# 输入框内翻译成英文

保持 Easydict 运行，并授予辅助功能权限。在可编辑输入框中键入 `/en 明天见、` 或
`/en 明天见|`，最后的 `、` 或 `|` 会触发翻译，也支持中文输入法的全角 `｜` 和反斜杠结束符。
Easydict 使用本机已安装的 Apple 翻译模型，取得完整英文译文后原地替换命令。
命令须位于输入框开头或空白之后，结束符须紧邻光标之前。

周围文字和剪贴板保持原样。等待翻译时继续键入、点击、移动光标或切换应用，都会阻止替换。
请求失败时保留原文并提示原因；删除结束符再重新输入即可重试。

此定制版本需要 macOS 26 或以上系统，以及对应的源语言、目标语言离线包。
在「系统设置 → 通用 → 语言与地区 → 翻译语言」中一次性下载简体中文和英语（美国）。
翻译请求不会下载语言包，也不会回退到在线服务。语言检测、OCR 和朗读使用 Apple 的本地功能；
在线翻译、在线 AI、网页搜索快捷键、遥测和更新检查均已禁用。
Apple Dictionary 与导入的 MDict 本地词典仍可使用。这是本版本的固定策略，无须填写 API key 或选择在线服务。

输入框须通过 macOS 辅助功能提供文本、选区和替换能力，密码框和不支持的控件不会被修改。
也支持粘贴完整命令来触发翻译。
